# 📻 راديو قرآن — Radio Quran

تطبيق ويب إسلامي متكامل (PWA) يعمل **بدون إنترنت** بعد أول زيارة. يضم إذاعات القرآن المباشرة، ومصاحف لعدد من القرّاء، والأذكار (حصن المسلم)، والأحاديث النبوية، والأدعية، وتفسير الشعراوي، والرقية الشرعية، ودروس عدد من المشايخ.

> 🔗 **النسخة المنشورة:** https://waleedd189.github.io/radio-quran/

---

## ✨ المميزات

- 🎙️ **إذاعات قرآن مباشرة** من عدّة محطّات (القاهرة، نابلس، السعودية، وغيرها).
- 🎧 **مكتبة الشيخ محمد أيوب عاصف**: ٦٧ تسجيلًا (حوالي ١٤ ساعة و٣١ دقيقة)، بحث وتصنيفات، مشغّل واحد، تشغيل متتابع وتكرار، وتحكم في الوقت والسرعة والصوت مع حفظ آخر موضع استماع محليًا. كارت المكتبة موجود في أول قسم بالرئيسية.
- 📺 **البث المباشر للحرمين**: قناة القرآن الكريم من مكة وقناة السنة النبوية من المدينة، بمشغّل «الأولى» الرسمي داخل الموقع. تشغيل قناة يوقف أي بث آخر؛ مع ملء الشاشة وإعادة التحميل ومؤقّت النوم.
  - البث الصوتي والمرئي يحتاج الإنترنت؛ وضع الأوفلاين للصفحات والأصول المحلية المحفوظة، وليس للبث الحي.
- 📖 **مصاحف كاملة** لقرّاء متعدّدين (مشاري العفاسي، المنشاوي، الحصري، فارس عباد، جبريل، القطامي، الطبلاوي…).
- 🔖 **المصحف للقراءة** يحفظ آخر صفحة وموضع التمرير تلقائيًا، مع خمس علامات مستقلة للعودة والحذف. الحفظ محلي على الجهاز والمتصفح.
- 💡 **إبقاء الشاشة مضيئة تلقائيًا داخل المصحف** عبر Screen Wake Lock، ما دام ظاهرًا؛ يتطلب دعم المتصفح والسماح منه، وقد تتدخل إعدادات توفير الطاقة.
- 🧕 **المصحف المعلم** للحصري (تعلّم التلاوة).
- 📿 **حصن المسلم** وأذكار الصباح والمساء.
- 📜 **الأحاديث النبوية** و**الأدعية** القرآنية والنبوية.
- 🎧 **تفسير الشعراوي** ومكتبة دروس (النابلسي، المغامسي، عمر عبد الكافي، راغب السرجاني، عائض القرني…).
- ⭐ **مفضلة** لحفظ المحطّات المفضّلة.
- 🌙 **وضع ليلي / نهاري** + دعم لغتين (عربي/إنجليزي).
- ⏱️ **مؤقّت نوم** لإيقاف التشغيل تلقائيًا.
- 📴 **عمل أوفلاين** بالكامل عبر Service Worker.
- 📱 قابل للتثبيت على الهاتف كتطبيق (PWA).

## 🚀 التشغيل محليًا

المشروع مكوّن من ملفات HTML/CSS/JS ثابتة بدون أي خطوة بناء. شغّل أي خادم ملفات بسيط في مجلد المشروع:

```bash
# بايثون 3
python3 -m http.server 8080

# أو Node
npx serve .
```

ثم افتح المتصفّح على: <http://localhost:8080>

> ⚠️ لازم التشغيل عبر خادم (مش فتح الملف مباشرة `file://`) حتى يعمل الـ Service Worker والأوفلاين بشكل صحيح.

## 📁 هيكل المشروع

| الملف / المجلد | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية: الإذاعات المباشرة، المفضلة، الإعدادات، اللغة، الوضع الليلي |
| `mohammad-ayyub-asif.html` | مكتبة تلاوات الشيخ محمد أيوب عاصف |
| `recitation-library.js` / `.css` | مشغّل المكتبة الواحد، البحث والتصنيفات والتحكم في الاستماع |
| `data/mohammad-ayyub-asif.json` | التسجيلات الـ٦٧ وروابطها الأصلية ومددها؛ لا تُعدّل ترميز أسماء الملفات أو تدمج العناوين المتشابهة |
| `sw.js` | Service Worker المسؤول عن التخزين والعمل أوفلاين |
| `mushaf.html` | مصحف QCF v4، 604 صفحات، مع حجم خط محدود بعرض الإطار |
| `mushaf-reading.js` / `mushaf-reading.css` | حفظ آخر موضع، خمس علامات محلية، وإبقاء الشاشة مضيئة أثناء القراءة |
| `live-tv.js` / `live-tv.css` | تضمين البث الرسمي للحرمين داخل لوحة المشغّل، دون حفظ روابط فيديو مؤقتة |
| `*-qari` / صفحات القرّاء | مصاحف القرّاء (لكل قارئ صفحة مشغّل خاص) |
| `mahmoud-khalil.html` | مصحف الحصري المرتّل |
| `mahmoud-khalil-muallim.html` | مصحف الحصري **المعلم** |
| `adhkar.html` / `hisn_almuslim.html` | الأذكار وحصن المسلم |
| `ahadith-1.html` | الأحاديث النبوية |
| `duas.html` | الأدعية القرآنية والنبوية |
| `sharawy-tafsir.html` | تفسير الشعراوي |
| `almushaf-qiraa.html` | المصحف الإلكتروني للقراءة |
| صفحات الدروس | النابلسي، المغامسي، عمر عبد الكافي، راغب السرجاني، عائض القرني، الزغبي… |
| `The_End.html` | برنامج النهاية (نبيل العوضي) |
